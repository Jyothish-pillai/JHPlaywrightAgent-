Search for a Product and Verify Product Information Page (PIP)

User Story ID: US_AMZ_001

Title: Search for a product and verify the Product Information Page (PIP)

As a customer using the Amazon application,
I want to search for the product "Dr.Ortho Flexi Ease Men Shoes", open the product by clicking its image,
So that I can view the Product Information Page (PIP) and verify that the correct product details are displayed.

Business Value

This feature ensures that customers can successfully search for a product and navigate to the correct Product Information Page (PIP), providing a seamless shopping experience.

Preconditions
The Amazon application is installed and accessible.
The user has internet connectivity.
The product "Dr.Ortho Flexi Ease Men Shoes" is available in the catalog.
Acceptance Criteria
Scenario 1: Search for the Product and Open PIP

Given

The Amazon application is launched successfully.

When

The user taps on the search bar.
The user enters "Dr.Ortho Flexi Ease Men Shoes".
The user initiates the search.
The search results are displayed.
The user clicks on the product image of "Dr.Ortho Flexi Ease Men Shoes".

Then

The Product Information Page (PIP) should open successfully.
The product title should contain "Dr.Ortho Flexi Ease Men Shoes".
The product image should be displayed.
The product price should be visible.
The product rating should be visible (if available).
The Add to Cart button should be displayed.
The Buy Now button should be displayed (if applicable).
No application error or crash should occur during navigation.
